# 일본 유학 플래너

무료 GitHub Pages 배포를 전제로 만든 로컬 저장형 PWA입니다.

## 포함 기능
- 대학 추가/수정/삭제 및 대학별 메모
- 입시 일정 추가/수정/삭제, 대학 연결, 종류별 필터
- 월간 달력
- 전체 메모 자동 저장
- IndexedDB 로컬 저장
- JSON 백업 및 복원
- PWA 설치 및 기본 오프라인 캐시

## GitHub Pages 배포
1. GitHub에서 새 **Public** 저장소를 만듭니다. 예: `japan-study-planner`
2. 이 폴더 안의 파일과 `icons` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택하고 Save를 누릅니다.
6. 배포가 끝나면 `https://사용자이름.github.io/japan-study-planner/` 주소로 접속합니다.
7. iPad Safari에서 접속한 뒤 공유 → 홈 화면에 추가를 선택합니다.

## 중요
- 대학/일정/메모 데이터는 IndexedDB에 저장되며 GitHub로 전송되지 않습니다.
- Safari 탭과 홈 화면 웹 앱은 저장 공간이 분리될 수 있습니다. 반드시 배포 주소에서 홈 화면에 추가한 앱을 처음 실행한 뒤 데이터를 입력하세요.
- 앱 삭제, 웹사이트 데이터 삭제, 저장 공간 정리로 로컬 데이터가 사라질 수 있습니다. 정기적으로 데이터 관리 메뉴에서 JSON 백업을 다운로드하세요.
- 이 버전은 기기 간 자동 동기화를 제공하지 않습니다.
- Google Fonts를 사용하므로 최초 글꼴 로딩에는 인터넷 연결이 필요할 수 있습니다.
